这是占位页面。后端 API（/api/v1/**）、AlertManager 接收端点与 /healthz、/readyz、/metrics 均已可用， 只是前端 SPA 尚未打包进二进制。

构建一次即可：

cd web && pnpm install && pnpm build
make web   # 把 web/dist 同步到 crates/alkh-server/web-dist
cargo build --release --bin alkh

前端开发时无需重新编译后端：设置 ALKH_STATIC_DIR=/绝对路径/web/dist 直接使用磁盘上的 Vite 产物。
